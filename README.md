# CISP 自检

CISP 题库 + 百词斩式记忆练习程序。

## 使用

下载 `index.html`，双击打开即可。单文件、无依赖、无需联网，题库和程序全部内联在这一个文件里，学习进度存在浏览器 localStorage。

## 学习逻辑

每道题是一张卡片，走 Leitner 盒子（box 0–5），间隔 1/2/4/7/15 天：

- 答对：盒子 +1，到 box5 记为「已掌握」
- 答错：退回 box1，进入错题本；已掌握的题答错退到 box2
- 错题本：连续答对 2 次才移出
- 一轮练习里答错的题会在本轮末尾再考一遍
- 复习优先于新题；到期复习量按 ±10% 抖动，避免同一天堆积

模式：每日学习、复习到期、错题本、模拟考试（100 题，70% 及格线）、知识域专项、题库浏览。

- 涉及图表的题目只有文字部分

## 构建流程

本仓库发布的是打包好的单文件。生成它的流程（需要 Node.js 与原始 PDF）：

```bash
npm install                # pdfjs-dist
node extract2.mjs          # PDF -> raw2/*.txt（按填充色保留红色答案标记）
node parse.mjs             # -> questions.json（解析 + 跨文件补答案 + 去重）
node build-bank.mjs        # -> bank.js（知识域分类）
node validate.mjs          # 题库质量检查，应为 0 issues
node test-app.mjs          # 学习逻辑单元测试（25 项）
node build-single.mjs      # 打包成单文件 cisp-quiz.html
```
